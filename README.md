# its-gegevenscatalogus

LET OP: Alles wat op deze omgeving gepubliceerd wordt is nog aan verandering onderhevig! De documentatie en de RDF's zijn nog niet bedoeld voor productie scenarios.

Deze repository bevat begrippenmodellen voor de geprioriteerde gegevensTypen (onderwerpen waarvoor data beschikbaar moet komen) zoals beschreven in ANNEX III van de ITS wetgeving.
Per gegevenstype is een map opegnomen. In de map zijn de RDF deliverables beschikbaar en kan via de README.MD doorgelinkt worden naar de Respec pagina waarin het begrippenmodenmodel beschreven is. 

De Respec documenten kunnen voorzien worden van review commentaar. Door een stuk tekst te selecteren in het Respec document komt er een knop 'review comment' beschikbaar. Na invullen van de benodigde gegevens zal er een Github issue worden aangemaakt wat opgepakt zal worden door NDW.
